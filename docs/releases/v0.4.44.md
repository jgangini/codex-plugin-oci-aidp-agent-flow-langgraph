# Distribución 0.4.44

Plugin 0.4.44 y motor Python 0.4.30. El marketplace conserva la identidad
`langchain-skills-codex`; las cinco skills upstream y sus hashes permanecen intactos.

El CLI valida los casos nativos antes de reservar consumo. `workflow status`
consolida observaciones locales y, con `--native`, el despliegue y Registry sin
publicar. La evidencia nueva por nodo admite reutilización ante cambios del plan
que no afectan su contrato; código, modelo, configuración y entorno siguen
invalidando evidencia. La aceptación integrada final permanece vinculada al plan
completo. Las guías explican pruebas parciales y calibración con controles positivos,
negativos y abstenciones válidas, sin umbrales universales.

## Alcance de validación

La distribución pasó `scripts/validate.py`: manifiestos, versiones del motor,
hashes upstream, corpus, enlaces locales, 3 controles del empaquetado y 521 pruebas
offline del plugin, incluidas 11 de conservación selectiva. Los 3 ejemplos del
tutorial también pasaron con fixtures y el entorno Python existente, sin instalar
dependencias ni llamar a proveedores. Estas pruebas no certifican todos los
tenants Oracle ni una calibración semántica general.

Sentrux conserva la referencia pública 0.4.8. El gate falla: 35 funciones complejas
frente a 26; la puntuación pasa de 6800 a 6764. Se mantienen cero ciclos y cero
god files. El incremento corresponde al conjunto de capacidades acumuladas desde
la distribución pública inicial y queda como deuda estructural pendiente; no se
reemplazó el baseline ni se declara la validación estructural aprobada.
No hay reglas Sentrux locales ni grafo Graphify en este repositorio.

Las campañas activas siguen usando su motor fijado. Instalar skills no cambia sus
recibos ni concede aceptación; una adopción del ejecutor se realiza por el flujo
de campaña existente.
