# Avisos de terceros

El plugin conserva los avisos MIT y de marcas en
[su aviso distribuido](plugins/langchain-skills-codex/THIRD_PARTY_NOTICES.md).
Las skills oficiales de LangChain se instalan por separado y conservan sus propias
licencias. No se redistribuyen dentro de este paquete.

El diagrama interactivo usa el runtime de
[Archify](https://github.com/tt-a1i/archify), distribuido bajo
[Apache-2.0](docs/diagrams/LICENSE-Archify.txt). El contenido propio y el plugin
se distribuyen bajo [MIT](LICENSE); la licencia del runtime permanece separada.
